# 포트폴리오 작성 틀 (구현 후 검증 수치만 기입)

## 프로젝트명
ChickenQA — Unreal Engine AI 테스트 및 디버깅 자동화 도구

## 한 줄 소개
언리얼 엔진 게임의 실행/자동 테스트 로그를 구조화해 분석하고, Gemini API를 이용해 오류 원인 후보와 재현 절차를 제안하는 QA 보조 도구.

## 배경과 문제
게임 플레이/충돌 판정 테스트를 반복하는 과정에서 많은 로그를 확인해야 했다. 반복적인 탐색·정리를 줄이고 재현 및 확인 절차를 기록하기 위해 자동화 도구를 제작했다.

## 담당 구현
- Python CLI로 UE 로그에서 Crash/Error/Warning 및 디버깅 이벤트 수집
- UE Automation JSON 결과 연계 (실제 UE에서 검증한 후만 완료 표시)
- Gemini API를 활용한 가설 기반 오류 분석 (실제 API에서 검증한 후만 완료 표시)
- Markdown/JSON 결과 자동 생성 및 명령줄 실행 파이프라인

## 기술적 선택과 이유
- Python: 파일·프로세스 자동화를 빠르게 구현
- Unreal C++ Automation Framework: 게임 로직의 실제 통과/실패 검증
- Gemini: 사람이 검토할 가설·재현 방법 생성, 정답 판정에는 사용하지 않음
- Markdown/JSON: QA 보고서의 접근성과 기계 판독 동시 확보

- 테스트 성공/실패 실제 검증: [ ] / [ ]

## 증빙으로 넣을 것
1. 원클릭 PowerShell 실행 화면
2. Unreal Tests Automation 실행 화면 / 리포트 JSON
3. 자동 생성된 Markdown 리포트 캡처(비식별화)
4. AI의 가설과 실제 수정 내역을 대조한 표
5. 코어 파서와 단위 테스트 코드 및 GitHub 주소
