# ChickenQA 프로젝트 로드맵

## 원칙

- 기존 `DKUEndGame` 소스 변경 없이 Python 독립 실행 도구부터 구현.
- **관측된 로그/자동 테스트 통과 여부**와 **AI의 추측**을 별도로 저장.
- 팀 비공개 로그는 사용자 동의 없이 외부 API에 보내지 않음.
- 팀원 파일은 승인 없이 수정하지 않고, AI 추천 패치는 별도 브랜치에서 검토.
